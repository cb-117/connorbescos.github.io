The one that matters

Security · Interface

Security review moved into the workstream.

GitHub’s Copilot app can now run /security-review against current workstream changes. The public-preview command returns findings scored by severity and confidence, plus suggestions that developers can apply and recheck before the code lands.

Operator read

Add the review where developers already steer the agent, but keep deterministic scanning, tests, and required human approval downstream. The win is a faster first security pass—not permission to collapse independent controls into one model judgment.
